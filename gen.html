הגדרות חיבור לריפו — פעם אחת
איך מייצרים טוקן:
  1. היכנס ל־Fine-grained tokens → Generate new token
  2. Token name: כל שם. Expiration: בחר שנה או No expiration
  3. Repository access → Only select repositories → בחר את הריפו הזה בלבד
  4. Permissions → Repository permissions → Contents → שנה ל־Read and write
  5. Generate token → העתק והדבק כאן → שמור
הטוקן נשמר בדפדפן הזה בלבד ונשלח רק ל־api.github.com. הגבל אותו לריפו אחד כפי שכתוב בסעיף 3 — כך גם אם יאבד, הנזק האפשרי מוגבל לתיקייה הזו.
